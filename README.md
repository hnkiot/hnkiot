HNK IoT Solutions (Pty) Ltd is a Cape Town based engineering company, registered with the CIPC
(Companies and Intellectual Property Commission) in South Africa. It is engineer led, not a
reseller: the same person and team who design the circuit and write the firmware also build the
cloud software on top of it, so support never dead ends at someone who has never seen the
schematic.

## What we do

| Area | Details |
|---|---|
| Embedded systems and firmware | ESP32, STM32, Arduino, bare-metal and RTOS |
| IoT and telemetry | MQTT, LoRaWAN, cellular, device to cloud pipelines |
| Software and dashboards | React, Python, C#, Node, cloud-connected dashboards |
| Electronics and prototyping | Proof of concept to working, testable board |
| Technical support and networking | Troubleshooting, Wi-Fi, structured cabling |
| Energy monitoring | Solar, battery storage (BESS), smart metering |
| Engineering training | One on one tutoring, workshops, project mentoring |

Working with clients across South Africa and internationally, in English and French.
